# LG 전자 서비스 매니저 전사원 과정 수강신청 및 관리 시스템

본 프로젝트는 LG전자 서비스 매니저 약 3,000명을 대상으로 기획된 **전사원 교육 과정**의 수강신청을 효과적으로 대행 및 통제하는 대시보드 형태의 고품격 웹 애플리케이션(SPA)입니다.

---

## 🎯 주요 기능 및 제약 조건

1.  **로그인 분기**
    *   **센터장 및 실장 성명/사번 로그인**: 소속 지역담당(수도권, 중부/강원실, 서남부/충청실)이 매핑되어 대시보드로 즉석 분기됩니다.
    *   **테스트용 가상 센터 생성**: 사전에 매핑되지 않은 임의의 사번을 입력해 로그인하더라도, 입력한 사번에 매칭되는 가상 신규 센터와 20명의 가상 구성원이 자동 생성되어 막힘없는 시연과 검증이 가능합니다.

2.  **지역담당별 수강신청의 완전 분리**
    *   3대 지역담당별로 각각 **독립된 1~30차수**가 생성되며, 로그인된 리더의 소속 지역에 맞춘 차수만 나타나고 수강 신청할 수 있습니다.

3.  **차수별 정원 60명 엄격 제한**
    *   차수마다 배정 가능한 최대 인원은 60명입니다. 60명이 초과되면 UI에 '정원마감' 배지가 뜨며, 추가적인 등록이 원천 차단됩니다.

4.  **교육 시작 2일 전 00:00(자정) 자동 잠금**
    *   개별 차수 시작일의 2일 전 자정(00:00:00)이 도래하면 수강신청, 차수 이동, 취소(삭제) 등 모든 수정 작업이 엄격히 잠금 처리됩니다.
    *   **통합 테스트 시뮬레이터 배너**가 최상단에 제공되어 가상 시스템 시각을 임의로 변경하며 마감 로직을 생생하게 연동 테스트해 볼 수 있습니다.

5.  **차수별 '어느 센터의 누가' 상세 명단 조회**
    *   대시보드 우측 차수 현황판에서 `신청자 보기` 버튼 클릭 시, 해당 차수에 소속된 타 센터 매니저들을 포함한 전체 구성원 리스트(센터명, 성명, 사번 등)를 가나다순으로 확인하여 협의 및 조율할 수 있습니다.

6.  **비밀번호 보호형 교육 아카데미 종합 콘솔 (관리자 페이지)**
    *   하단 비밀 링크 진입 후 패스워드 `2026`을 검증하여 활성화됩니다.
    *   전사 수강신청 현황 차트 및 지역별 필터링 기능.
    *   개별 차수의 교육 일정을 즉석에서 캘린더 인풋으로 강제 변경해 볼 수 있어 마감 기능 시뮬레이션 지원.
    *   **BOM CSV 엑셀 내보내기**: 전체 명단 및 특정 차수/지역 명단을 Excel에서 한글 깨짐 없이 곧바로 열 수 있는 UTF-8 BOM 인코딩 포맷으로 다운로드합니다.

## 💻 설치 및 로컬 실행 방법

본 시스템은 순수 HTML5, CSS3, ES6 Javascript만으로 설계된 정적 웹 어플리케이션이므로, 별도의 Node.js 설치나 빌드 과정 없이 다운로드 후 바로 열어 테스트할 수 있습니다.

### 1. 일반 더블 클릭 실행
프로젝트 폴더 내의 `index.html` 파일을 크롬(Chrome)이나 엣지(Edge) 브라우저로 직접 더블 클릭하여 실행합니다.

### 2. 초경량 로컬 웹 서버 실행 (원격 모바일/타인 시연용)
터미널을 열고 프로젝트 폴더 경로에서 파이썬 웹 서버를 작동시킵니다.
```bash
python -m http.server 8000
```
이후 웹 브라우저를 열고 `http://localhost:8000` 혹은 본인의 내부 IP 주소(`http://192.168.x.x:8000`)를 공유해 회의실의 동료들과 실시간으로 링크 접속하여 시연을 공유할 수 있습니다.
